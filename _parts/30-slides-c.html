PROJECT LOOP

每個專案，只要記住三句話

第一次「初始化專案」建藍圖、交接檔、作業成果，並檢查電腦
→
每次上課「開工」讀交接檔，告訴你上次做到哪
→
做作品下指令生成成果都放進「作業成果」
→
下課前「收工」寫好交接，換電腦也接得上

開工 → 做 → 收工，每次上課重複。全部做完再說「寫學習歷程報告」。

示範：新開一個資料夾，在 Codex 裡說「初始化專案」，讓全班看 AI 問了哪些問題（專案名稱、班級座號、想做什麼、期限）。

只問班級與座號，不問姓名；學生資料不寫進藍圖。

開工和收工都不碰 git、不上傳任何東西。換電腦時，要把整個專案資料夾（含作業成果）一起帶過去。

INIT · 初始化專案

「初始化專案」會做兩件事

① 建好專案

  • AGENTS.md 藍圖（含「成果放哪」的規則）
  • handoff.md 交接檔
  • 作業成果\ 圖片、影片、文件

② 檢查你的電腦

ComfyUI有沒有裝、連不連得上
生圖模型有沒有可用的模型檔
讀 PDF／寫 Word寫學習歷程報告要用

缺的東西，AI 會先問你同意才補裝；不會自己去下載模型。沒有 ComfyUI 也沒關係，可以先用 Codex 內建的生圖。

環境檢查是只讀的：看常見安裝位置、連線埠 8188，以及 models 資料夾下的 checkpoints／diffusion_models／unet 有沒有模型檔。

學校的 ComfyUI 若放在學校主機，連線位址由老師提供（可設為環境變數 COMFYUI_URL）。【待老師提供】

模型檔很大、來源不可信，所以 AI 不得自己下載；缺什麼就回報給老師。

Python 套件（python-docx 等）安裝前一定先問學生同意，失敗就停下請學生找老師。

PROMPTS · 圖片

範例提示語：照著改成你的題目

範例 1 ｜ 基本款

請幫我生成一張圖片：一隻戴圓框眼鏡的橘貓，坐在圖書館窗邊看書，水彩插畫風格，柔和的午後光線，畫面不要有文字。存到專案的「作業成果\圖片」，檔名用「日期_戴眼鏡的貓」，存好後告訴我檔名與位置。

範例 2 ｜ 校園用途

幫我做一張社團博覽會的海報底圖：直式、主色藍與橘、扁平插畫風格，中間留一塊空白之後放標題。不要出現真人臉孔與文字。存到「作業成果\圖片」，不要覆蓋舊檔，完成後告訴我檔名。

範例 3 ｜ 改一點再生

剛剛那張很好，但請把貓的眼鏡改成紅色，其他保持不變。另存成新檔，不要覆蓋原本那張，存到「作業成果\圖片」。

黃字＝主體＋場景＋風格。再加上「放哪、不要什麼、存好告訴我」，就是前面的四件事。

這頁只教「怎麼下指令」，不教 ComfyUI 工作流與進階提示語技巧，那部分由美術老師接手。

讓學生先照抄範例 1 生成，再改主體、場景、風格各換一個，觀察結果怎麼變。

重點不是畫得多漂亮，是練習把「放哪、不要什麼、怎麼驗收」講清楚。範例 3 示範「改一點再生」：不要整個重來，這樣省點數也比較可控。

提醒：不要用同學或老師的臉當素材；不確定能不能用的圖片，先問老師。

【待實測】Codex 內建生圖是否可用、輸出位置，請先在教室電腦試過。

PROMPTS · 影片

影片：先有一張圖，再讓它動起來

範例 4 ｜ 圖片變短影片

請用老師指定的影片生成工具，把「作業成果\圖片\20261007_戴眼鏡的貓.png」做成 3 秒短影片：貓輕輕翻書頁，窗外光線微微移動，鏡頭固定。影片存到「作業成果\影片」，完成後告訴我檔名與長度。

範例 5 ｜ 工具不能用時

如果影片生成工具現在不能用，請告訴我原因，以及缺少什麼。不要自己去網路下載軟體或模型，也不要改我的設定。

影片要用到哪個工具、能不能在你的電腦上跑，依學校環境而定，以老師當天說明為準。

【待實測】影片生成的可用工具與流程（學校 ComfyUI 是否有影片工作流、連線位址），目前沒有實測，請老師確認後再決定這一頁要不要現場示範。

這頁刻意不寫任何工作流細節，只示範「怎麼對 Agent 交辦」與「工具不能用時要它回報，而不是亂裝東西」。

先用一張圖確認畫面對，再做影片；影片比圖片更耗點數，不要一次生一堆。

STEP 1 · 兩句話生出初稿

步驟一：兩句話，先有一個網站

全班先用同一份

請上網搜尋最近一個月〔K-pop〕的〔演唱會、來台活動和熱門舞蹈資訊〕，整理成一個單頁網站，存到專案的「作業成果\網站」。網站要有〔「近期行事曆」「熱門舞蹈連結」「追星用語」〕三個區塊，用繁體中文，手機也能看，每筆資料都附來源網址。

1送出指令等 Agent 搜尋與製作
→
2打開 index.html用瀏覽器看初稿
→
3點兩筆來源確認日期與內容是真的

〔藍底虛線〕＝可以換成你自己的：主題（偶像、運動、遊戲…）、想看的資訊、網站區塊。換完再送出。

全班同一份指令，10 分鐘內人人有初稿，先求有成就感。只給目標與成果，不講語法。

資料是 AI 搜尋來的，可能過期或搜錯，所以要求附來源並親自核對，是媒體識讀練習。

Threads 需要登入，Agent 通常抓不到，用一般網頁搜尋即可。

【待實測】教室環境的搜尋能力與網頁預覽方式，上課前先跑一次。

STEP 2 · 引導探索需求

步驟二：一次改一件，改完再看

問 1換哪一個？內容、外觀、功能三選一
→
問 2要什麼感覺？一句話，不講技術
→
改貼句型給 Agent先說做法，我同意再動手
→
問 3重新整理看結果不滿意就「恢復上一版」
外觀

請把網站改成〔舞台、暗底螢光粉〕的感覺，先給我兩種配色，我選了你再改。

功能

我想加〔演唱會倒數計時〕，請先用白話說明做法，我同意再動手。

質感

請找出這個網站最不專業的三個地方，列給我看，我選要不要改。

〔藍底虛線〕＝換成你的想法。交件：至少改一次外觀、加一個功能，並說得出「為什麼這樣改」。

不要問「你想改什麼」，學生沒經驗答不出來；改成三選一，再用感覺描述。卡住時問：「你想讓看網站的人有什麼感覺？」

「恢復上一版」是安全網，學生知道能退回就敢嘗試。第三句讓 Agent 當審查員，不需設計經驗也能提升質感。

改內容：「把主角換成〔團名〕，資料重新搜尋，一樣附來源網址。」

可替換處：步驟一的〔主題〕〔資訊類型〕〔網站區塊〕，步驟二的〔氛圍〕〔功能〕。藍底虛線＝替換處，複製後括號可保留或刪掉。主題不限 K-pop，示範用。

REPORT · 學習歷程報告

作品，變成學習歷程報告

原料 1作業成果圖片、影片、文件
＋
原料 2對話歷程你下過的指令與修改
＋
原料 3你的幾句省思簡單說就好
→
AI寫成草稿問你同不同意
→
完成Word 報告你同意才寫入

對 AI 說「寫學習歷程報告」。AI 只寫真的發生過的事；你沒同意的省思，不會寫進去。交出去之前，自己從頭看一遍。

學習歷程中的「課程學習成果」每項有百字簡述；本報告依序是課程名稱、成果簡述、學習歷程、成果展示、學習省思。學校若有指定範本或字數，以學校為準。【待老師提供】

對話紀錄會自動遮蔽金鑰與密碼；報告最後附「AI 使用說明」，誠實揭露圖片是 AI 生成、文字經學生同意。

省思的流程：AI 問三個小問題 → 學生回答一兩句 → AI 代寫 150–300 字 → 問「同意嗎？」→ 學生同意才寫入。學生也可以選擇直接用自己的原句。

【待實測】Codex 對話紀錄的存放位置（~/.codex/sessions）。讀不到時，學生可以貼上重要指令與結果。

TAKE AWAY

今天帶走這幾件事

  • Agent 做事，Chat AI 只講話
  • 專案資料夾＝工作間；藍圖＝記憶
  • 桌面會塞滿：一次一件事、換題目開新任務
  • 交辦四件事：做什麼、用什麼、不做什麼、驗什麼
  • 領點數、套用、新任務、再核對
  • Token 與密碼不貼、不借、不傳
  • 「初始化專案」→「開工」→「收工」
  • 作品一律放進「作業成果」
