池預算

這堂課的總額度，全班共用，用完就沒了

PER PERSON

每人額度

你個人最多能用多少，不會增加全班的總額度

TIME

有效時間

只在課程日期與開放的時段內能用

三個限制任何一個用完或不符，你就不能用——所以不要亂送大量內容、不要一直重生。

這是平台（NMKING AI Gateway）的分享者視角概念：老師建立「點數池」，設定總預算、每人上限與開放時間，學生領取後在池內共同消耗。

個人額度是「軟上限」：已開始的請求可以做完，所以實際用量可能略超過；增加個人上限不會增加整個池的預算。

沒有教學生如何建池，那是老師的事，這裡只讓學生知道為什麼有時候會「突然不能用」。

班級密碼

老師口頭或寫在黑板告訴你，自己在網頁輸入。不要貼在群組。

不要換瀏覽器

免登入領取沒有復原碼。換電腦或清除瀏覽器資料後，不一定打得開同一份設定。

課前由老師在平台設定免登入領取、約定識別名稱格式（例如座號）、設定班級密碼。班級密碼不寫在這份簡報、也不放進 GitHub。

第 5 步一定要讓學生看一眼「池名稱／模型／有效時間」是不是這堂課的，對不上就舉手。

下載的 ZIP 是學生自己的，裡面含連線設定（等同密碼），不要傳給別人、不要貼到班級群組。

平台畫面會更新，以學生當下看到的為準；真人帶做時邊投影邊走一遍。

APPLY · 套用設定

讓 Codex 接上專案點數池

1存好工作作業都在原位
→
2解壓縮 ZIP右鍵 → 全部解壓縮
→
3雙擊套用檔1-套用-NMKING-Codex.bat
→
4完全關閉 Codex連背景程式也關
→

→
6核對提供者、點數池、模型

看到 Windows 警告、或套用檔跑不起來：先舉手問老師，不要自己繞過，也不要用別人的 ZIP。

套用工具會「改動個人的 Codex 連線設定」，不會搬移專案。所以第 1 步一定先存好工作。

舊任務可能還記著先前的提供者設定；一定要「建立新任務」，再核對提供者、點數池、模型。

【待實測】Codex 畫面上確認提供者與點數池的實際位置，請先在教室電腦走一遍再補充到這頁。

新任務開起來之後，對 AI 說「開工」就能接回進度（下面會講）。

SWITCH · 切換

個人設定 ⇄ 專案點數池，來回切換

「個人」是學生自己的 Codex 帳號／額度；「專案」是老師開的點數池。上課只用專案池，下課前才切回個人，避免用掉個人額度或把課外內容算進課程用量。

還沒下課前不要切回個人設定。

每個人保有自己的工作區與專案，不需要交換帳號或 Token。切換不會搬動專案資料夾。

【待實測】復原檔在 Windows 上的實際檔名，以 ZIP 內為準（開頭是「2-」）。

KEEP IT SAFE

三條規則，不要踩

1

不貼出去

Token、設定 ZIP、班級密碼，不貼群組、不給別人；截圖要遮住 Token。

2

不交換

每人用自己的設定。借用或交換會讓用量算錯人，也查不出誰做了什麼。

3

出問題先記下來

記下時間、做了什麼、錯誤文字，告訴老師；不要附上 Token。

這三條出自平台操作手冊：分享者可以查看學員狀態與用量，但不應要求學員把完整 Token 或含 Token 的設定 ZIP 貼到班級群組。

排錯順序：先看領取連結是否本次課程、再看有效時間與時段、再看個人與整池剩餘量、最後看模型。一次只調整一項。

學生「看起來像有點數但不能用」，最常見的是舊任務還在用舊設定，或不在開放時段。
