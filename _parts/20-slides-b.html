CHAT AI VS AGENT

Chat AI 回答你，Agent 幫你做完

Chat AI（聊天）

你問
→
它回文字
→
你自己貼
  • 只輸出文字，碰不到你的檔案
  • 你是操作者：複製、貼上、存檔
  • 關掉視窗，就忘了

Agent（做事）

給目標
→
拆步驟
→
用工具
→
看結果
  • 能讀寫你指定的資料夾，檔案直接存好
  • 你是驗收者：看成品對不對
  • 有藍圖和交接檔，下次接得上

比喻：問路 vs 叫車——問路你自己走；叫車它自己轉彎，但你要說得出目的地。

核心一句：聊天 AI 是「講」，Agent 是「做」。兩者背後都是同一類語言模型，差別在外面接了什麼。

Agent 的中間是一個迴圈：想 → 用工具 → 看結果 → 再想，直到做完或碰到停點。

提醒：Agent 不是每次走一模一樣的步驟，同一句話這次先做 A、下次先做 B 都正常；要驗的是成品，不是過程。

THE PARTS

Agent＝一位聰明、但每天上班都失憶的工讀生

技能不是新能力，只是放在桌上的一份 SOP 說明書。

用這張圖把五個詞一次對起來：LLM＝腦袋、Context＝桌面、Memory＝交接本、Tools＝手上的工具、Harness＝管家兼制度；Agent＝全部合起來。

學生最容易混的是 Context 與 Memory：Context 只在這次對話，關掉就沒；Memory（藍圖、交接檔）是寫在檔案裡，下次還在。

Codex 就是這裡的 Harness，不是 LLM。換一個模型，Codex 還是 Codex。

LLM VS HARNESS

大腦負責想，管家負責做

LLM｜大腦

  • 產出的只有文字，連「請執行這個指令」也只是文字
  • 不在你的電腦上，在遠端
  • 你的點數，就是用在它的運算上

Harness｜管家（Codex）

  • 真的讀檔、寫檔、跑工具、畫畫面
  • 決定它能碰哪些資料夾、哪些動作要先問你
  • 工具失敗時，把錯誤丟回給大腦重想

注意：管家在你的電腦上動手，但想事情是在外面想的。它讀到的內容會被送出去——不要讓它讀個人資料或密碼。

一句話：LLM 是 API 背後的算力與大腦；Harness 是讓這份能力能被安全控制、能真正動手的外殼。

常見誤會：「它在我電腦上跑，所以沒有上傳。」錯。它先在你電腦上把檔案內容讀出來，再送到模型那端。「在我電腦上跑」不等於「資料沒離開我的電腦」。

紅字報錯不用急著中斷：這是管家把錯誤丟回去讓大腦重想，正常運作。反而要小心「失敗了還說完成」，所以最後一定自己驗收。

CONTEXT

桌面會被塞滿：每問一句，整桌重送一次

越長越慢、越貴：你的點數用得更快。

聊久了會變笨：桌面被舊內容擠滿。

怎麼辦：一次只做一件事、換題目就開新任務、重要規則寫進藍圖。

Context 與 Memory 對照：Context＝桌面，只在這次對話、有上限、每輪整份重送；Memory＝交接本，跨對話保留。

「AI 忘記我剛剛說的話」多半是 Context 問題（桌面被擠爆），不是交接本丟了。

token 可理解為「字數的計價單位」，中文通常比英文更耗。這就是為什麼我們要在上課前先領「點數」，用量是共用的、有限的。

所以開新任務不只是讓它變聰明，也是為了省點數。

PROJECT FOLDER

專案資料夾：Agent 的工作間

我的AI專案\
├─ AGENTS.md   藍圖：目的與規則
├─ handoff.md  交接：上次做到哪
├─ CLAUDE.md   一行橋接檔
└─ 作業成果\   所有生成的檔案
   ├─ 圖片\
   ├─ 影片\
   └─ 文件\

三個重點

① Agent 只在你指定的資料夾裡工作。

② 藍圖和交接檔就是它的 Memory，不用每次重講。

③ 作品一律放進「作業成果」，之後才找得到、交得出去。

AGENTS.md 是 Codex 等工具會自動讀的藍圖；Claude Code 讀的是 CLAUDE.md，所以放一個只寫「@AGENTS.md」的橋接檔，兩邊共用同一份。

換一台電腦、換一個新任務，只要說「開工」，AI 讀這兩份檔案就接得上。

「作業成果」是本課的硬規定：之後的學習歷程報告就是從這個資料夾整理出來的。

技能不是新增的能力，也不是更強的模型；同一顆腦袋，只是桌上多了一份說明書。

常見誤會：「技能是程式，我不會寫」——它是純文字；「技能會一直待命」——要被觸發才載入。

這五個技能都在老師準備好的技能包裡，學校電腦已經裝好（或由 AI 協助安裝），學生只需要記得「怎麼叫它」。

HOW TO ASK

交辦事情，說清楚四件事

1 做什麼

要的成品長什麼樣

「一張直式海報底圖」

2 用什麼

拿哪些資料做

「用我放在 作業成果\圖片 的草稿」

3 不做什麼

哪裡不能碰、做到哪停

「不要出現真人臉孔；不要覆蓋舊檔」

4 驗什麼

你要核對哪一項

「存好後告訴我檔名與位置」

口訣：做什麼、用什麼、不做什麼、驗什麼。漏掉其中一項，八成就要重來。

新手交辦失敗，多半是漏了其中一項：漏了「做什麼」會得到一坨散文；漏了「用什麼」它會自己編；漏了「不做什麼」可能一路做到底；漏了「驗什麼」你不知道錯在哪。

第 4 問要寫具體：寫「存好後告訴我檔名與位置」比「檢查一下」有用。但它的回報只是線索，你還是要自己打開成品看。

後面的「範例提示語」就是照這四件事寫出來的。
