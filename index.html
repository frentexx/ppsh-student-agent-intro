這是平台（NMKING AI Gateway）的分享者視角概念：老師建立「點數池」，設定總預算、每人上限與開放時間，學生領取後在池內共同消耗。

個人額度是「軟上限」：已開始的請求可以做完，所以實際用量可能略超過；增加個人上限不會增加整個池的預算。

沒有教學生如何建池，那是老師的事，這裡只讓學生知道為什麼有時候會「突然不能用」。

SWITCH · 切換

個人設定 ⇄ 專案點數池，來回切換

「個人」是學生自己的 Codex 帳號／額度；「專案」是老師開的點數池。上課只用專案池，下課前才切回個人，避免用掉個人額度或把課外內容算進課程用量。

還沒下課前不要切回個人設定。

每個人保有自己的工作區與專案，不需要交換帳號或 Token。切換不會搬動專案資料夾。

【待實測】復原檔在 Windows 上的實際檔名，以 ZIP 內為準（開頭是「2-」）。

CHAT AI VS AGENT

Chat AI 回答你，Agent 幫你做完

Chat AI（聊天）

你問
→
它回文字
→
你自己貼
  • 只輸出文字，碰不到你的檔案
  • 你是操作者：複製、貼上、存檔
  • 關掉視窗，就忘了

Agent（做事）

給目標
→
拆步驟
→
用工具
→
看結果
  • 能讀寫你指定的資料夾，檔案直接存好
  • 你是驗收者：看成品對不對
  • 有藍圖和交接檔，下次接得上

比喻：問路 vs 叫車——問路你自己走；叫車它自己轉彎，但你要說得出目的地。

核心一句：聊天 AI 是「講」，Agent 是「做」。兩者背後都是同一類語言模型，差別在外面接了什麼。

Agent 的中間是一個迴圈：想 → 用工具 → 看結果 → 再想，直到做完或碰到停點。

提醒：Agent 不是每次走一模一樣的步驟，同一句話這次先做 A、下次先做 B 都正常；要驗的是成品，不是過程。

THE PARTS

Agent＝一位聰明、但每天上班都失憶的工讀生

技能不是新能力，只是放在桌上的一份 SOP 說明書。

用這張圖把五個詞一次對起來：LLM＝腦袋、Context＝桌面、Memory＝交接本、Tools＝手上的工具、Harness＝管家兼制度；Agent＝全部合起來。

學生最容易混的是 Context 與 Memory：Context 只在這次對話，關掉就沒；Memory（藍圖、交接檔）是寫在檔案裡，下次還在。

Codex 就是這裡的 Harness，不是 LLM。換一個模型，Codex 還是 Codex。

LLM VS HARNESS

大腦負責想，管家負責做

LLM｜大腦

  • 產出的只有文字，連「請執行這個指令」也只是文字
  • 不在你的電腦上，在遠端
  • 你的點數，就是用在它的運算上

Harness｜管家（Codex）

  • 真的讀檔、寫檔、跑工具、畫畫面
  • 決定它能碰哪些資料夾、哪些動作要先問你
  • 工具失敗時，把錯誤丟回給大腦重想

注意：管家在你的電腦上動手，但想事情是在外面想的。它讀到的內容會被送出去——不要讓它讀個人資料或密碼。

一句話：LLM 是 API 背後的算力與大腦；Harness 是讓這份能力能被安全控制、能真正動手的外殼。

常見誤會：「它在我電腦上跑，所以沒有上傳。」錯。它先在你電腦上把檔案內容讀出來，再送到模型那端。「在我電腦上跑」不等於「資料沒離開我的電腦」。

紅字報錯不用急著中斷：這是管家把錯誤丟回去讓大腦重想，正常運作。反而要小心「失敗了還說完成」，所以最後一定自己驗收。

CONTEXT

桌面會被塞滿：每問一句，整桌重送一次

越長越慢、越貴：你的點數用得更快。

聊久了會變笨：桌面被舊內容擠滿。

怎麼辦：一次只做一件事、換題目就開新任務、重要規則寫進藍圖。

Context 與 Memory 對照：Context＝桌面，只在這次對話、有上限、每輪整份重送；Memory＝交接本，跨對話保留。

「AI 忘記我剛剛說的話」多半是 Context 問題（桌面被擠爆），不是交接本丟了。

token 可理解為「字數的計價單位」，中文通常比英文更耗。這就是為什麼我們要在上課前先領「點數」，用量是共用的、有限的。

所以開新任務不只是讓它變聰明，也是為了省點數。

PROJECT FOLDER

專案資料夾：Agent 的工作間

我的AI專案\
├─ AGENTS.md   藍圖：目的與規則
├─ handoff.md  交接：上次做到哪
├─ CLAUDE.md   一行橋接檔
└─ 作業成果\   所有生成的檔案
   ├─ 圖片\
   ├─ 影片\
   └─ 文件\

三個重點

① Agent 只在你指定的資料夾裡工作。

② 藍圖和交接檔就是它的 Memory，不用每次重講。

③ 作品一律放進「作業成果」，之後才找得到、交得出去。

AGENTS.md 是 Codex 等工具會自動讀的藍圖；Claude Code 讀的是 CLAUDE.md，所以放一個只寫「@AGENTS.md」的橋接檔，兩邊共用同一份。

換一台電腦、換一個新任務，只要說「開工」，AI 讀這兩份檔案就接得上。

「作業成果」是本課的硬規定：之後的學習歷程報告就是從這個資料夾整理出來的。

技能不是新增的能力，也不是更強的模型；同一顆腦袋，只是桌上多了一份說明書。

這五個技能都在老師準備好的技能包裡，學校電腦已經裝好（或由 AI 協助安裝），學生只需要記得「怎麼叫它」。

HOW TO ASK

交辦事情，說清楚四件事

1 做什麼

要的成品長什麼樣

「一張直式海報底圖」

2 用什麼

拿哪些資料做

「用我放在 作業成果\圖片 的草稿」

3 不做什麼

哪裡不能碰、做到哪停

「不要出現真人臉孔；不要覆蓋舊檔」

4 驗什麼

你要核對哪一項

「存好後告訴我檔名與位置」

口訣：做什麼、用什麼、不做什麼、驗什麼。漏掉其中一項，八成就要重來。

新手交辦失敗，多半是漏了其中一項：漏了「做什麼」會得到一坨散文；漏了「用什麼」它會自己編；漏了「不做什麼」可能一路做到底；漏了「驗什麼」你不知道錯在哪。

第 4 問要寫具體：寫「存好後告訴我檔名與位置」比「檢查一下」有用。但它的回報只是線索，你還是要自己打開成品看。

後面的「範例提示語」就是照這四件事寫出來的。

PROJECT LOOP

每個專案，只要記住三句話

第一次「初始化專案」建藍圖、交接檔、作業成果，並檢查電腦
→
每次上課「開工」讀交接檔，告訴你上次做到哪
→
做作品下指令生成成果都放進「作業成果」
→
下課前「收工」寫好交接，換電腦也接得上

開工 → 做 → 收工，每次上課重複。全部做完再說「寫學習歷程報告」。

示範：新開一個資料夾，在 Codex 裡說「初始化專案」，讓全班看 AI 問了哪些問題（專案名稱、班級座號、想做什麼、期限）。

只問班級與座號，不問姓名；學生資料不寫進藍圖。

開工和收工都不碰 git、不上傳任何東西。換電腦時，要把整個專案資料夾（含作業成果）一起帶過去。

INIT · 初始化專案

「初始化專案」會做兩件事

① 建好專案

  • AGENTS.md 藍圖（含「成果放哪」的規則）
  • handoff.md 交接檔
  • 作業成果\ 圖片、影片、文件

② 檢查你的電腦

ComfyUI有沒有裝、連不連得上
生圖模型有沒有可用的模型檔
讀 PDF／寫 Word寫學習歷程報告要用

缺的東西，AI 會先問你同意才補裝；不會自己去下載模型。沒有 ComfyUI 也沒關係，可以先用 Codex 內建的生圖。

環境檢查是只讀的：看常見安裝位置、連線埠 8188，以及 models 資料夾下的 checkpoints／diffusion_models／unet 有沒有模型檔。

學校的 ComfyUI 若放在學校主機，連線位址由老師提供（可設為環境變數 COMFYUI_URL）。【待老師提供】

模型檔很大、來源不可信，所以 AI 不得自己下載；缺什麼就回報給老師。

Python 套件（python-docx 等）安裝前一定先問學生同意，失敗就停下請學生找老師。

PROMPTS · 圖片

範例提示語：照著改成你的題目

範例 1 ｜ 基本款

請幫我生成一張圖片：一隻戴圓框眼鏡的橘貓，坐在圖書館窗邊看書，水彩插畫風格，柔和的午後光線，畫面不要有文字。存到專案的「作業成果\圖片」，檔名用「日期_戴眼鏡的貓」，存好後告訴我檔名與位置。

範例 2 ｜ 校園用途

幫我做一張社團博覽會的海報底圖：直式、主色藍與橘、扁平插畫風格，中間留一塊空白之後放標題。不要出現真人臉孔與文字。存到「作業成果\圖片」，不要覆蓋舊檔，完成後告訴我檔名。

範例 3 ｜ 改一點再生

剛剛那張很好，但請把貓的眼鏡改成紅色，其他保持不變。另存成新檔，不要覆蓋原本那張，存到「作業成果\圖片」。

黃字＝主體＋場景＋風格。再加上「放哪、不要什麼、存好告訴我」，就是前面的四件事。

這頁只教「怎麼下指令」，不教 ComfyUI 工作流與進階提示語技巧，那部分由美術老師接手。

讓學生先照抄範例 1 生成，再改主體、場景、風格各換一個，觀察結果怎麼變。

重點不是畫得多漂亮，是練習把「放哪、不要什麼、怎麼驗收」講清楚。範例 3 示範「改一點再生」：不要整個重來，這樣省點數也比較可控。

提醒：不要用同學或老師的臉當素材；不確定能不能用的圖片，先問老師。

【待實測】Codex 內建生圖是否可用、輸出位置，請先在教室電腦試過。

PROMPTS · 影片

影片：先有一張圖，再讓它動起來

範例 4 ｜ 圖片變短影片

請用老師指定的影片生成工具，把「作業成果\圖片\20261007_戴眼鏡的貓.png」做成 3 秒短影片：貓輕輕翻書頁，窗外光線微微移動，鏡頭固定。影片存到「作業成果\影片」，完成後告訴我檔名與長度。

範例 5 ｜ 工具不能用時

如果影片生成工具現在不能用，請告訴我原因，以及缺少什麼。不要自己去網路下載軟體或模型，也不要改我的設定。

影片要用到哪個工具、能不能在你的電腦上跑，依學校環境而定，以老師當天說明為準。

【待實測】影片生成的可用工具與流程（學校 ComfyUI 是否有影片工作流、連線位址），目前沒有實測，請老師確認後再決定這一頁要不要現場示範。

這頁刻意不寫任何工作流細節，只示範「怎麼對 Agent 交辦」與「工具不能用時要它回報，而不是亂裝東西」。

先用一張圖確認畫面對，再做影片；影片比圖片更耗點數，不要一次生一堆。

REPORT · 學習歷程報告

作品，變成學習歷程報告

原料 1作業成果圖片、影片、文件
＋
原料 2對話歷程你下過的指令與修改
＋
原料 3你的幾句省思簡單說就好
→
AI寫成草稿問你同不同意
→
完成Word 報告你同意才寫入

對 AI 說「寫學習歷程報告」。AI 只寫真的發生過的事；你沒同意的省思，不會寫進去。交出去之前，自己從頭看一遍。

學習歷程中的「課程學習成果」每項有百字簡述；本報告依序是課程名稱、成果簡述、學習歷程、成果展示、學習省思。學校若有指定範本或字數，以學校為準。【待老師提供】

對話紀錄會自動遮蔽金鑰與密碼；報告最後附「AI 使用說明」，誠實揭露圖片是 AI 生成、文字經學生同意。

省思的流程：AI 問三個小問題 → 學生回答一兩句 → AI 代寫 150–300 字 → 問「同意嗎？」→ 學生同意才寫入。學生也可以選擇直接用自己的原句。

【待實測】Codex 對話紀錄的存放位置（~/.codex/sessions）。讀不到時，學生可以貼上重要指令與結果。
